# Reconcile with an attached handover

Read from the handover skill's §3. When this thread attached a handover and you are about to write the new one.

**Skip this only if this thread attached no handover.** Otherwise open the one
you attached, read its open-work section **and its mission front matter**, and
account for **every** item in it. Four outcomes, and each is written down
somewhere:

| Outcome | Where it goes |
|---|---|
| Done this thread | your **State** section, in one line |
| Still open, and it belongs to the mission | **the mission spec's Backlog**: move it there, then point at it |
| Still open, and it is this thread's own loose end | your **Open work** section |
| Deliberately dropped | your **Open work** section, with the reason |

There is no fifth outcome. "I did not get to it" is *still open*, not silence.

**Migrating an item to the spec is the point, not extra work.** Once it is
there, the next thread inherits it from a durable file rather than from your
diligence in retyping it, and this document gets *shorter* down the chain. Do
not copy an item into both places: a backlog in two files is two backlogs, and
they will disagree.

**The mission is itself an item to reconcile.** If the predecessor declared
`mission_status: live` and this thread did not advance it, that is an outcome
you write down in the Mission section, not an omission.

**This step is the only thing that carries a non-mission item forward.** §2
routes "what is half-done, what to do next" to *this* document by design, so it
never reaches memory, and nothing checks that a successor inherited it. An item
the successor does not mention survives only in a file nobody will open again.

**Read the predecessor's open items, not its narrative.** You are looking for
what it said was unfinished, not a summary of what it did.

**This does not license reporting other sessions' work as yours.** §0's leak
table still holds for every *sibling* file in the handover directory. The
handover you attached is the one exception, because you inherited it.
